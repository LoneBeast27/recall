# Quality comparison frames

Setup uses the matching `*-frame.png` images at 640 × 360. Its detail toggle and the settings popovers use the zoomed crops of the same frame.

Shown by the (i) beside Settings → Clip → Bitrate and Encoder effort
(`src/views/quality_preview.rs`). Made by `tools/quality-previews/make-previews.ps1` on an
NVIDIA GPU with the engine's NVENC settings; see that script for how.
