## Recall 0.1.6 for Windows

**What's new**
- **Fixes** (Settings › Help): when Recall spots a problem it knows how to fix, it offers the fix there. Nothing changes until you choose **Fix**; the **(i)** view lists every change first, **Undo** takes back only what is still Recall's, and **Not now** is remembered. The first fix makes the overlay show on **Minecraft: Java Edition with an NVIDIA graphics card**: Recall adds its own "Recall: Minecraft" NVIDIA app profile for the Java program that runs the game, never edits an existing profile, and needs no administrator prompt. Every program on that Java build gets the setting, wherever it is installed. A yellow dot on Settings and the Help tab shows when a fix is waiting.
- **Island editor panel**: the **Place the island for this game** shortcut now shows a panel with the island's size for this game (75% to 150%), one-click places (Top, Bottom, Left, Right, Centre), and **⟲ Auto**, **Cancel** and **Done**. It never takes the focus from your game and is hidden from recordings.
- **Set up FPS** (Settings › General › Overlay): when the stats island cannot read FPS because your account is not in Windows' Performance Log Users group, one click asks Windows once and adds your own account. Setup also asks after an install or update while it is missing.
- **Help tab in Settings**: Fixes, Report a problem and About (with the update check) moved there from General; the MIDI device moved to Recording, under **Advanced audio**.

**Improved**
- In a corner the cursor picks the island's edge, so it no longer flips between its two looks while you move it.
- The island size you set also scales the stats pill over your game.
- Same-version hotfixes are found when Recall starts (since the 0.1.5 hotfix).

**Fixed**
- The show-overlay shortcut (Ctrl+Alt+O) always says "Overlay shown" and what came back, also when only the stats island is on outside a game.

**Install**
Download `RecallSetup.exe` and run it. An installed Recall offers the update by itself; your settings are kept, and settings from every earlier version load unchanged. During the update, a recording in progress is stopped and saved.

**Unsigned installer**
This release is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**. See the [code signing policy](https://github.com/LoneBeast27/recall/blob/main/CODE_SIGNING_POLICY.md) for how to check the download.

`SHA256SUMS.txt` lists the installer's checksum, and `SOURCE-REVISION.txt` names the exact source commit.
