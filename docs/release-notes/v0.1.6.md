## Recall 0.1.6 for Windows

**What's new**
- **Island editor panel**: the **Place the island for this game** shortcut now shows a panel with the island's size for this game (75% to 150%), one-click places (Top, Bottom, Left, Right, Centre), and **⟲ Auto**, **Cancel** and **Done**. It never takes the focus from your game and is hidden from recordings.
- **Set up FPS** (Settings › General › Overlay): when the stats island cannot read FPS because your account is not in Windows' Performance Log Users group, one click asks Windows once and adds your own account. Setup also asks after an install or update while it is missing.
- **FPS fix notice**: when the stats island can't read FPS for lack of the Windows permission, a one-line notice offers **Fix**, which asks Windows once and adds your own account; **Undo** removes only what Recall added. Sign out and back in for it to apply.
- **Help tab in Settings**: Report a problem and About (with the update check) moved there from General; the MIDI device moved to Recording, under **Advanced audio**.
- **Rocket League island fix**: when Rocket League's Fullscreen mode hides the island, a one-line notice offers **Fix**, which switches the game to its own Borderless mode (two lines in its settings file, only while the game is closed, with a backup). **Undo** puts them back.

**Improved**
- **Lighter recording on older Windows**: on Windows before 11 24H2, Recall drops the frames above its capture rate itself before any processing, instead of working on every frame a fast game draws.
- **Less background work**: Recall waits for Windows to report changes instead of checking several times a second; the recording engine does about 20% less work while idle.
- **Faster hover previews**: the preview frames of a clip on an SSD now come from one ffmpeg run instead of eight, about 2.7 times faster, with the same pictures.
- **Stats over games cost less**: the stats pill shows for a few seconds when a game comes to the front and after each notice; **Keep stats on screen** (Settings › General) keeps it up as before, and is on for you if your stats were on. The overlay stays loaded while hidden, so showing it again has no delay, and the placement grid shows only while you drag. When FPS drops sharply, Recall saves the last 5 minutes of FPS numbers (numbers only) to a small file on your PC, to help with bug reports.
- **Lighter recording on the graphics card**: each captured frame is converted to the video encoder's own format on the graphics card's video engine, and screenshots read the captured frame directly instead of a copy. Measured with a test game: the game ran about 9% faster while recording (881 to 960 fps), Recall's graphics work fell by about a quarter, and it uses about 48 MB less video memory. Clips look the same or slightly closer to the game, and screenshots are pixel-exact as before.
- In a corner the cursor picks the island's edge, so it no longer flips between its two looks while you move it.
- The island size you set also scales the stats pill over your game.
- Same-version hotfixes are found when Recall starts (since the 0.1.5 hotfix).

**Fixed**
- The show-overlay shortcut (Ctrl+Alt+O) always says "Overlay shown" and what came back, also when only the stats island is on outside a game.
- After a game closes, Recall no longer keeps retrying its closed window.

**Install**
Download `RecallSetup.exe` and run it. An installed Recall offers the update by itself; your settings are kept, and settings from every earlier version load unchanged. During the update, a recording in progress is stopped and saved.

**Unsigned installer**
This release is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**. See the [code signing policy](https://github.com/LoneBeast27/recall/blob/main/CODE_SIGNING_POLICY.md) for how to check the download.

`SHA256SUMS.txt` lists the installer's checksum, and `SOURCE-REVISION.txt` names the exact source commit.
