## Recall 0.1.7 for Windows

**Improved**
- **Update progress you can trust**: Check now and the update download show a progress bar that only moves forward. The download is measured byte by byte; the short steps around it (connecting, checking the download, opening Setup) move by how long they took before.

**Fixed**
- **Check now no longer times out**: one of GitHub's download servers does not answer from some networks, and Recall gave up before Windows moved on to the next one. Recall now waits long enough, tries once more, and says "GitHub did not answer in time" instead of "The download timed out."
- **Scrolling stays in the update notes**: scrolling the notes in the update window no longer scrolls the clips behind it. The same goes for the game-folder and recovered-clips prompts.

**Install**
Download `RecallSetup.exe` and run it. An installed Recall offers the update by itself; your settings are kept, and settings from every earlier version load unchanged. During the update, a recording in progress is stopped and saved. If Check now in 0.1.6 times out, try it again.

**Unsigned installer**
This release is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**. See the [code signing policy](https://github.com/LoneBeast27/recall/blob/main/CODE_SIGNING_POLICY.md) for how to check the download.

`SHA256SUMS.txt` lists the installer's checksum, and `SOURCE-REVISION.txt` names the exact source commit.
