## Recall 0.1.9 for Windows

**Fixed**
- **Dragging an export out of Recall works again**: dragging a finished export onto another app, or copying it as a file, failed with "could not reference" because of the long-path form Windows gave its path. It works again, and the clip is always copied, never moved.
- **Show in folder opens the right folder**: for a clip whose name or folder has spaces, the folder icon opened Documents instead. It now opens the clip's folder with the clip selected.
- **Updating never saves the replay buffer**: an update used to save the replay buffer as a clip on its way out. Now only a recording you started is stopped and saved first.

**Install**
Download `RecallSetup.exe` and run it. An installed Recall offers the update by itself; your settings are kept, and settings from every earlier version load unchanged. During the update, a recording you started is stopped and saved first; the replay buffer is not saved.

**Unsigned installer**
This release is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**. See the [code signing policy](https://github.com/LoneBeast27/recall/blob/main/CODE_SIGNING_POLICY.md) for how to check the download.

`SHA256SUMS.txt` lists the installer's checksum, and `SOURCE-REVISION.txt` names the exact source commit.
